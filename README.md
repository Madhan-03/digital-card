# 👨‍💻 Digital Business Card

My Digital Business Card is a modern responsive web-based application designed to showcase my professional profile, technical background, contact information, and social media links.

It provides a clean and interactive interface for recruiters and visitors to connect with me, explore my portfolio, and view or download my resume.

---

# 🚀 Features

* 📱 Fully Responsive Modern Design.
* ⌨️ Animated Typing Text Effect.
* 👨‍💻 Professional Profile & About Me Section.
* 📞 Contact Information.
* 📄 View & Download Resume.
* 🌐 Social Media Integration.
* ✨ Smooth Animations & Interactive UI.

---

# 🛠️ Tech Stack

* **Frontend       :** HTML, CSS, JavaScript
* **Icons          :** Font Awesome
* **Deployment     :** GitHub Pages
* **Resume Hosting :** Google Drive

---

# 🎯 Objective

The goal of this project is to create a professional digital business card that presents my skills, professional background, and contact details in a simple and accessible format for recruiters and professional networking.

---

# 📌 Future Improvements

* QR Code for Easy Profile Sharing.
* Save Contact Details Feature.
* Dark / Light Mode.
* Share Digital Card Functionality.
